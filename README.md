Ichi's Otter Pet
A cute little desktop otter that walks around, takes occasional naps, and collects little items.

About the Project
Ichi's Otter Pet is a 2D desktop pet game made with Godot Engine. Inspired by my best friend, who loves otters and everything blue, I wanted to create a small, interactive otter with animations and collectible objects. This project is a personal learning experience where I explored game development, GDScript, sprite animations, movement, and interactive objects.

Features
- Otter Movement — The otter walks around the screen.
- Idle Animation — The otter occasionally pauses and plays an idle animation.
- Collectible Items — Includes a blue pebble, blue pen, ladybug, and blue gem.
- Buying System — Interact with items to open a dialog where you can buy them from the otter or return them.
- Coin System — The otter earns coins when players buy items from the otter. The coin display updates according to the otter's balance and the value of each item.
- Fish Treat — Drag the fish treat anywhere on the screen.
- Feeding Mechanic — When the otter reaches the fish treat, it automatically spends 3 coins to buy it.
- Fish Respawning — The fish returns to the center when you have at least 3 coins. If you have fewer than 3 coins, it disappears until you earn enough again.
- Custom Art — All graphics for the otter and its items were created by me.

Built With
- Godot Engine
- GDScript
- Custom art via Ibis Paint

How to Run
1. Download or clone this repository.
2. Open Godot Engine.
3. Import the project by selecting its `project.godot` file.
4. Open the `Main` scene.
5. Run the project.

What I Learned:
While making this project, I learned more about:
- Creating scenes and nodes in Godot.
- Using GDScript to control character movement.
- Setting up walking and idle animations.
- Making objects draggable and collectible.
- Using distance checks to detect when the otter is near an item.
- Creating interactive dialogs and a simple selling system.
- Managing an in-game currency balance and deducting coins for purchases.
- Using conditions to control when objects disappear and respawn.
- Debugging errors and understanding how node hierarchies affect a game.

Why I Made This:
-I wanted to make something cute and personal for my best friend. I chose an otter and added small items that reflect things they like. I kept the artwork simple so I could focus on learning how to make the game interactive.
-This is one of my favorite projects in game development, and I'm excited to keep learning and improving it. Made with care, pixel art, and lots of debugging.
