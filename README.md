Ichi's Otter Pet

A cute little desktop otter that walks around, takes occasional naps, and collects little items.

About the Project

Ichi's Otter Pet is a 2D desktop pet game made with Godot Engine. Inspired by my best friend, I wanted to create a small, interactive otter with cute animations and collectible objects.

This project is a personal learning experience where I explored game development, GDScript, sprite animations, movement, and interactive objects.

Features

- Otter Movement — The otter walks around the screen.
- Idle Animation — The otter occasionally pauses and plays an idle animation.
- Collectible Items — The otter can pick up items when it gets close to them.
- Selling System — Interact with carried items to open a dialog where you can sell or return them.
- Coin Feature — A coin that can be moved around the screen as the otter's money token.
- Custom Pixel Art — Includes original artwork for the otter and its collectible items.

Built With

- Godot Engine
- GDScript
- Custom pixel art assets

How to Run

1. Download or clone this repository.
2. Open Godot Engine.
3. Import the project by selecting its `project.godot` file.
4. Open the `Main` scene.
5. Run the project.

What I Learned

While making this project, I learned more about:

- Creating scenes and nodes in Godot.
- Using GDScript to control character movement.
- Setting up walking and idle animations.
- Making objects draggable and collectible.
- Using distance checks to detect when the otter is near an item.
- Creating interactive dialogs and experimenting with a simple selling system.
- Debugging errors and learning how node hierarchies affect a game.

Why I Made This
I wanted to make something cute and personal for my best friend. I chose an otter and added small items that reflect things they like. I kept the artwork simple so I could focus on learning how to make the game interactive.
This is one of my projects as a beginner in game development, and I'm excited to keep learning and improving it.
Made with care, pixel art, and lots of debugging.
